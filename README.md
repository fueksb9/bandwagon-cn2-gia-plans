## 先搞清楚：搬瓦工不是“WordPress 主机”

BandwagonHost 是 IT7 Networks 旗下、运营了二十多年的 VPS 品牌，卖的是 KVM 虚拟化服务器，官网明确定位为“Self-Managed（自管）”。这意味着：

- 你拿到的是一台有独立 IP、root 权限的 Linux 服务器，系统支持 AlmaLinux、Debian、Ubuntu、CentOS 等主流发行版；
- 硬件、网络、机房由搬瓦工负责，OS 之上的所有事情——装 Web 环境、配数据库、更新插件——都归你自己管；
- 没有托管型主机常见的图形化“一键建站”向导，但可以通过宝塔面板这类免费工具把操作门槛降下来，后面会讲具体步骤。

这个模式不是缺点，而是它能把价格压下来的原因。托管型 WordPress 主机的钱，一部分就是付给“帮你管服务器”这件事的。

那为什么 WordPress 站长还是愿意选它？核心在线路。搬瓦工的 CN2 GIA 方案走中国电信 AS4809 高端路由，并且接入了联通 CUP 和移动 CMIN2 的优质链路。国内访问的延迟普遍在 150ms 上下，晚高峰丢包控制得比较好，这是普通美国 VPS 做不到的。如果你的读者、客户主要在国内，而主机又必须放海外，这条线路基本就是选它的理由。

## 在搬瓦工上跑 WordPress 的完整流程

以最常见的“宝塔面板 + WordPress”路线为例，整个过程大概半小时到一小时：

1. **购买并进入 KiwiVM 面板**。下单后系统会发邮件给你 KiwiVM 的登录信息。这个控制面板是搬瓦工自研的，支持重装系统、切换机房、管理快照等核心操作。
2. **安装系统**。KiwiVM 里选 AlmaLinux 或 Debian 重装，推荐较新的稳定版本。
3. **SSH 登录，一键安装宝塔面板**。官方提供一键安装脚本，几条命令的事。
4. **在宝塔里装 LNMP 环境**。Nginx + MySQL + PHP，全部图形化点选，不用手敲配置文件。
5. **添加站点并解析域名**。在域名服务商处把 A 记录指向 VPS 的 IP，宝塔里绑定域名。
6. **一键部署 WordPress**。宝塔后台直接下载 WordPress 程序包，创建数据库，走完安装向导。
7. **上 HTTPS**。宝塔自带 Let's Encrypt 证书一键申请，三个月自动续期。

两个值得注意的点：一是宝塔面板记得改默认端口、加访问限制，暴露在公网的面板是常见攻击面；二是搬瓦工提供免费自动备份和快照功能（KiwiVM 里可永久保留两个快照），在动大改动之前先拍一个，出问题能几秒钟回滚。对 WordPress 来说，这些快照加上插件备份，基本覆盖了大部分翻车场景。

| 中国方向线路 | CN2 GIA 三网优化 | 基本没有专门优化 |
| 资源隔离 | KVM 独立资源，无邻居干扰 | 共享主机有超售风险 |
| 技术支持 | 工单/知识库，不碰 OS 层问题 | 有专人管插件、缓存、报错 |

简单说：如果你能接受“自己管服务器”这个前提，搬瓦工用差不多同样的钱给你更干净的资源和中国方向的真实优化；如果你连 SSL 证书都不想碰，托管主机省下来的时间更值钱。

**不满意能退吗？** 有 30 天退款保障，但条件要看清：账户注册 30 天内、账户下 VPS 少于 3 个、累计支付额低于 $100、支付次数少于 10 次，退款时账户下所有服务都会被删除。买之前把这些条件过一遍，避免到时候卡住。
